now to explain my project, its kinda simple, you the player should find and destroy ships 
how my project works :
1.it uses random.randint function to create the r and c (row and colom) of the ships
2.it then creates an array of buttons with individual r ac c (row and colom)
3.the game ads the ships r and c to a dictonary
4.it checks when a player hits a button whether the r and c matches the r and c of the ship dictonary
5.and finally if it is equal it shows a custom hit glow and box arround it.
